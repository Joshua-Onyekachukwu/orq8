# ORQ8: 90-Day Execution Plan
## Week-by-Week Tactics to First 50 Customers

---

## Week 1-2: Fix the Conversion Funnel

### Goal: 5% visitor → signup conversion

**What to build/fix:**
- [ ] Landing page: Add "See it in action" interactive demo (not video)
- [ ] Landing page: Add ROI calculator ("Save $X/month vs hiring")
- [ ] Landing page: Add 3 concrete use cases with before/after
- [ ] Pricing page: A/B test $49 vs $79 for Founder plan
- [ ] Signup flow: Reduce to 2 fields (email, password) — org name can come later
- [ ] Onboarding: Pre-configure AI employees based on company type selection
- [ ] Onboarding: Show "first win" within 5 minutes (e.g., generate a report)

**Metrics to track:**
- Visitor → signup rate (target: 5%)
- Signup → onboarding complete rate (target: 60%)
- Onboarding complete → first AI task rate (target: 80%)

**Tools to add:**
- PostHog or Mixpanel for funnel analytics (free tier)
- Hotjar for session recordings (free tier)
- Simple analytics dashboard in the app

## Week 3-4: Launch Beta Program

### Goal: 50 active beta users, 5 case studies

**What to do:**
- [ ] Email all 200+ waitlist signups: "You're invited to ORQ8 Beta"
- [ ] Offer 30-day free trial (full features, no credit card)
- [ ] Set up Slack/Discord for beta feedback
- [ ] Schedule 10 user interviews (30 min each)
- [ ] Document 5 success stories with metrics
- [ ] Create "Beta User" badge in the app

**Email sequence:**
1. Day 0: Welcome + quick start guide
2. Day 1: "Did you try the Command Center?"
3. Day 3: "Here's what other beta users are building"
4. Day 7: "Your first week stats are in"
5. Day 14: "Upgrade to keep your AI employees working"
6. Day 21: "Last week of beta — here's what you'll miss"
7. Day 28: "Your beta is ending — upgrade now"

**Key metrics:**
- Beta activation rate (target: 40%)
- Beta → paid conversion (target: 30%)
- Net Promoter Score (target: 50+)

## The One Metric That Matters

**Activation rate.**

If you fix activation (signup → first value in <10 minutes), everything else gets easier:
- Higher conversion = more customers
- Higher activation = lower churn
- Lower churn = higher LTV
- Higher LTV = more revenue
- More revenue = no need to raise

**Focus on activation. Everything else follows.**
