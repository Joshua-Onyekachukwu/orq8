# ADR-004 — LiteLLM as the Model Gateway

**Status:** **Superseded by [ADR-023](ADR-023.md)** (OpenRouter is the production model gateway) · **Date:** 2026-08 · **Scope:** Model abstraction

> ADR-023 changes which service is the production gateway, not the principle below:
domain code still never calls a provider SDK directly, and LiteLLM remains a
supported **development-only** gateway tried last, after OpenRouter and NVIDIA NIM.

## Context
The platform must be model- and provider-agnostic with routing, fallback, cost tracking, and virtual keys — and free-first (self-hostable).

## Decision
Use **LiteLLM** (MIT) as the self-hosted gateway. Add **Ollama** as a provider so the platform runs at $0 model cost. Domain code never calls provider SDKs directly.

## Consequences
- One interface for OpenAI/Anthropic/Gemini/DeepSeek/Groq/OpenRouter/Ollama/OpenAI-compatible endpoints.
- Centralized cost tracking + fallback; org-scoped virtual keys.
- Gateway is operational infrastructure; upgrade path to LiteLLM Cloud/Enterprise if ever needed.
