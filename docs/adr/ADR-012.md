# ADR-012 — Configurable Embedding Dimension

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Memory/retrieval

## Context
An early schema draft hard-coded `embedding vector(1536)` (OpenAI's size). The platform is Ollama-first, where nomic-embed-text is 768-dim; other models differ.

## Decision
The embedding dimension is **deployment-configurable** (`EMBED_DIM`), defaulting to the configured embedding model (768 for Ollama nomic-embed-text; 1536 for OpenAI text-embedding-3-small). Never hard-coded.

## Consequences
- Free/local memory retrieval works out of the box; switching embedding providers is a config + migration (re-embed) change.
- Vector column type is deployment-specific; keep the model choice in one config value.
