# ADR-005 — MinIO Now, R2/S3 Later

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Object storage

## Context
Need object storage for documents, repository artifacts, backups — self-hosted and free now, managed when funded, without rework.

## Decision
Use **MinIO** (S3-compatible) self-hosted now. When funded, switch the S3 endpoint config to **Cloudflare R2 / AWS S3** — same S3 API, zero code changes (ADR guidance per brief §57).

## Consequences
- Free, local-first storage; S3 client libraries work unchanged.
- MinIO is AGPL-3.0 — used as a **separate service via the S3 protocol**, never linked into product code (47_THIRD_PARTY_LICENSES).
- R2/S3 swap is an endpoint/config change (42, 53).
