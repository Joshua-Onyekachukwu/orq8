# ADR-002 — Drizzle ORM over Prisma

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Data access layer

## Context
Need a TypeScript-first ORM for PostgreSQL 16 + pgvector, lightweight, with migration tooling and no lock-in.

## Decision
Use **Drizzle** (Apache-2.0). First-class pgvector support, SQL-like ergonomics, no codegen lock-in.

## Consequences
- SQL-adjacent queries; easy to drop to raw SQL where needed.
- Migrations via `drizzle-kit`; forward-only per deployment (43).
- No Prisma engine binary or generated client to maintain.
