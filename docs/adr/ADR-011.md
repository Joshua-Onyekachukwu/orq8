# ADR-011 — Employee Polymorphism: Agent-Only for v1

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Domain/schema

## Context
The brief defines Employee as "agent or, in future, human employee" (§3). Early schema drafts mixed agent FKs (`agents.manager_agent_id`, `goals.owner_agent_id`, `tasks.assignee_agent_id`) with a polymorphic pattern (`team_members.employee_type`).

## Decision
**v1 is agent-only**: managers/owners/assignees are agent FKs. The polymorphic `employee_type (agent|user)` pattern (as in `team_members`) is reserved for future human employees. No polymorphic refactor now.

## Consequences
- Simpler queries and FKs at the cost of future schema change.
- When human employees arrive, add polymorphic owner refs (or separate join tables) as a migration — recorded as a new ADR at that time.
- Documented, deliberate; no silent half-support of human employees.
