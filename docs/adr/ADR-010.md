# ADR-010 — Platform-Native Engineering Agent (No Third-Party Core)

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Architecture

## Context
Codebuff/OpenHands offer agent+tooling+sandbox capabilities, but a third-party coding application must not dictate the architecture of the entire organization platform (§42).

## Decision
Build a **platform-native Engineering Agent** interface and tool layer (29, 30). Study/reuse suitable open-source components (Codebuff, OpenHands) **only where license and architecture permit** — never as the orchestration backbone. Verify licenses before any code reuse (47).

## Consequences
- The org OS stays coherent: one runtime, one authority model, one audit trail.
- We forgo some off-the-shelf agent capability in exchange for architectural control.
- OpenHands (MIT) is a candidate for *studied components*; Codebuff's file-picker/planner/reviewer patterns are reference designs.
