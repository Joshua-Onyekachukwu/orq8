# ADR-015 — financial_controls as the Single Source of Truth for Budgets

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Financial governance

## Context
An early schema draft had both `departments.budget_defaults jsonb` and `financial_controls(entity_type=department)` — duplicate, divergent budget state.

## Decision
**`financial_controls` is the single source of truth** for allocations, warnings, ceilings, and authorities. `departments.budget_defaults` is removed.

## Consequences
- One code path for budget checks (24.4, 24.7); no divergence possible.
- Department defaults derive from financial_controls rows, not a separate field.
