# ADR-016 — Runtime Record Tables

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Schema additions

## Context
Completing the documentation set surfaced runtime entities not in the original schema: hiring business cases, import runs, sandbox runs, simulation runs, eval runs, and first-class KPIs.

## Decision
Add tables: `business_cases`, `import_runs`, `sandbox_runs`, `simulation_runs`, `agent_eval_runs`, and `kpis` (34_DATABASE_SCHEMA §34.3 / Runtime records).

## Consequences
- Each lifecycle has durable state: hiring, import, sandbox, simulation, evaluation.
- KPIs are queryable first-class objects feeding snapshots, health, and reports (16).
- Migrations are additive; no existing table changes.
