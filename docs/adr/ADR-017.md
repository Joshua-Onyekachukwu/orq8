# ADR-017 — Minimal Simulation Ships with Phase 6

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Phasing

## Context
The Golden Workflow (step 10) simulates a workforce before hiring, but the full simulation engine is Phase 15 — leaving the v1 gate dependent on a later phase.

## Decision
A **minimal cost/workload simulation** (agents × expected tasks × model prices + infra share) ships with Golden Workflow v1 (Phase 6). The full simulation engine (org, risk, scenario comparison) remains Phase 15.

## Consequences
- v1 gate is self-contained; hiring proposals are informed by a basic forecast.
- Full simulation replaces/extends the minimal one without rework (41 §41.5).
