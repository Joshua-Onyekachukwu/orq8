# ADR-001 — Fastify over NestJS/Express

**Status:** Accepted · **Date:** 2026-08 · **Scope:** API layer

## Context
The platform needs a Node.js API framework supporting modular domain services, high throughput for SSE/streaming, low overhead, and freedom to compose domain modules without framework opinions.

## Decision
Use **Fastify** (MIT, plugin architecture). Modular services per domain (`auth`, `organizations`, `agents`, …) registered as Fastify plugins. No NestJS (heavy, opinionated DI) and no plain Express (less structure for a many-domain API).

## Consequences
- Fast, schema-based validation, first-class streaming (SSE) support.
- Domain boundaries are preserved as plugin modules, so a future migration (if ever needed) is contained.
- Team must follow Fastify conventions; thin custom wrapper for consistent routing/errors.
