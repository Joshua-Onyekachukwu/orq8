# ADR-014 — Golden Workflow v1 / Full Split

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Architecture validation / phases

## Context
The Phase 6 DoD claimed "Golden Workflow e2e passes," but the full workflow (§04.2) requires simulation (Phase 15), build/buy + engineering workspace (8/9/11), performance/replacement (12), and full reporting (14) — an impossible gate.

## Decision
Split the Golden Workflow:
- **v1 (Phase 6 gate):** steps 1–13, 17–18, 21, 24 + minimal cost tracking + v1 weekly report + minimal cost/workload simulation.
- **Full (after Phases 12–15):** all 25 steps.
Canonical spec: 04_GOLDEN_WORKFLOW.md §4.6; gates in 49 and 50.

## Consequences
- Phase 6 has a real, passable validation gate that still exercises the full architecture loop.
- The full workflow remains the north-star acceptance scenario.
- Requirement [M1] tags are scoped to v1 via 02 §2.17.
