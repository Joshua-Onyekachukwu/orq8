# ADR-009 — Docker Sandbox First, gVisor/Firecracker Later

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Code execution isolation

## Context
Agent-directed code must never run with host access. Isolation must be free, simple, and improvable.

## Decision
Run all engineering execution in **ephemeral Docker containers** via the Docker API (isolated filesystem, network policy, resource limits, timeout, secrets isolation, command allow/deny). Evaluate **gVisor/Firecracker** in Phase 16 for stronger kernel isolation.

## Consequences
- Containers give us most of the isolation we need at Phase 9 with minimal tooling.
- Hardening is a runtime swap, not an architecture change (30_CODE_EXECUTION_SANDBOX §30.4).
- Docker socket access is itself sensitive — only the sandbox service touches it.
