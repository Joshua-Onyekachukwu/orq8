# ADR-007 — Session Auth over JWT

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Authentication

## Context
Need revocable authentication that supports kill switches, membership changes, and emergency controls — immediately, with no token-revocation complexity.

## Decision
Server-side **sessions** (hashed token in `sessions` table, expiry, revocation on logout/password change/emergency). **Argon2id** password hashing. JWT is not used for auth. **OIDC/SSO** is a later adapter (Keycloak or managed).

## Consequences
- Instant revocation: emergency pause, role changes, and offboarding take effect immediately.
- Extra DB read per request (acceptable; cacheable).
- Enterprise SSO is additive later, not a rewrite.
