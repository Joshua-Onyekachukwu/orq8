# ADR-019 — Permission Namespace

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Authorization

## Context
The Golden Workflow and governance docs used ad-hoc permission names (`org:convene`, `org:create`) with no canonical namespace — ambiguity before Phase 5 builds the Authz service.

## Decision
Canonical permission namespace: **`{domain}:{resource}:{action}`** — e.g., `org:convene`, `dept:hire`, `agent:offboard`, `tool:github:merge`, `memory:read`, `budget:approve`, `finance:transfer`, `comm:send`, `constitution:amend`. Defined in the Approval Engine doc (19 §19.2) and consumed by Authz (18), tools (25), and approvals.

## Consequences
- One vocabulary across docs, code, and audit records.
- New capabilities extend the registry without rework.
