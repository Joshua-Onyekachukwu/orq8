# ADR-018 — v1 Weekly Report Ships with Phase 6

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Phasing

## Context
Weekly/monthly reporting is Phase 14, but the Golden Workflow closes with "weekly/monthly reports continue" (step 25) — and the CEO loop needs the Report→Learn step from the start.

## Decision
A **v1 weekly report** (PA agent drafts, Executive Agent reviews — core sections only) ships with Golden Workflow v1 (Phase 6). Full weekly/monthly reporting (all sections, scheduling, dashboards) remains Phase 14.

## Consequences
- The v1 gate exercises the full loop: intent → execute → report → learn.
- Full reporting extends v1 rather than replacing it (40 §40.4).
