# ADR-008 — SSE Before WebSockets

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Realtime

## Context
The UI needs live updates: decision center, agent activity, org health. Today the flow is one-directional (server → client).

## Decision
Use **SSE** (server-sent events) on `/v1/events` for client fan-out. Reserve **WebSockets** for the engineering terminal and voice (bidirectional needs) later.

## Consequences
- Simpler, HTTP-native, auto-reconnect, free; works through proxies.
- WebSocket adoption later is scoped to specific features, not the whole stack.
