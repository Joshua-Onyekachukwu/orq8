# ADR-020 — Event Catalog Extensions

**Status:** Accepted · **Date:** 2026-08 · **Scope:** Events

## Context
Golden Workflow and domain docs referenced events missing from the catalog (36): `spend.executed`, `simulation.run`, `hiring.proposed`, sandbox/import/eval events.

## Decision
Extend the catalog (36 §36.4):
- Hiring: `hiring.proposed/approved/rejected/cancelled`
- Finance: `spend.executed`, `payment.executed`
- Simulation/import/sandbox/eval: `simulation.run/completed`, `import.started/discovered/mapped/proposed/activated/failed`, `sandbox.run_started/completed/failed`, `eval.run_completed`

## Consequences
- Every consequential step in the Golden Workflow has a matching event.
- Consumers (reporting, activity feed, audit) subscribe to a complete vocabulary.
